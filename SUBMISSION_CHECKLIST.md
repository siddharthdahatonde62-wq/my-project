# Submission checklist

## Hackathon rules (from the event brief)
- [ ] Project built during the hackathon (commit history shows the work)
- [ ] Open-weight AI is a core part (Qwen2.5 + nomic-embed-text via Ollama)
- [ ] **Public** GitHub repository (check by opening the link in a private/incognito window)
- [ ] Open-source license present (MIT `LICENSE`, real team names in the copyright line)
- [ ] README has setup steps, features, demo instructions, and names the models and tools used
- [ ] Not a renamed copy of someone else's project

## Repo quality
- [ ] No `venv/`, `chroma_db/`, `uploads/*` or `.pyc` files committed
- [ ] No private PDFs committed (only `data/sample_pdfs/`)
- [ ] `docs/CampusProof_Project_Documentation.pdf` added
- [ ] Screenshots added to the README
- [ ] Demo video link added to the README
- [ ] Release tagged: `git tag v1.0 && git push --tags`

## Verification
- [ ] A teammate on **Windows** cloned fresh into a new folder and got it running using only the README
- [ ] `python backend/evaluate.py` run with your 20-25 questions, pass rate noted
- [ ] Demo rehearsed twice, under 3 minutes

## Submit
- [ ] Open the official submission page of the event (Devpost / MLH portal / form: use the link the organisers gave you)
- [ ] Paste: repo URL, video URL, short description, tech stack, team members
- [ ] Screenshot the confirmation page
