# my-project
CampusProof frontend demo (HTML5 + CSS3 only)

Files:
- index.html       Dashboard
- ask.html         Static AI chat demonstration
- documents.html   Sample document library
- deadlines.html   Sample deadlines and calendar
- saved.html       Saved answer cards
- settings.html    Profile and privacy settings UI
- style.css        Shared styles for all pages

How to run:
1. Extract the campusproof folder.
2. Open index.html directly in your browser.
3. Use the sidebar links to navigate between pages.

Important:
This is a static UI prototype. Search, upload, chat submission, toggles, persistence,
and calendar controls are not functional. No JavaScript or external UI framework is used.
